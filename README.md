# AURA PLM System

Оконная PLM-программа для состава изделия: **проект → сборка → деталь**.  
Интерфейс в стиле SolidWorks. Документы хранятся в JSON.

Версия 0.1.0.

## Аккаунт

При запуске открывается экран **Войти** / **Регистрация**. Первый зарегистрированный пользователь — администратор PLM.

- Пароль хранится как хеш (PBKDF2). Документ AURA шифруется ключом аккаунта.
- Хранилище: `Документы\AURA_Vault\<логин>\` — у каждого своё.
- **Убрать всё** у чек-листа (и замена своего списка) спрашивает пароль текущего аккаунта.
- **Аккаунт → Сменить пароль** / **Запросы на удаление** / **Выйти**.
- Файлы хранилища обычный пользователь не удаляет: только запрос. Администратор одобряет паролем — тогда папка узла удаляется.

Файл, сохранённый под одним пользователем, другой открыть не сможет.

## Запуск

Нужен Python 3. Для фото/JPEG/GIF и просмотра STEP:

`pip install -r requirements.txt`

(Pillow и gmsh).

- Двойной щелчок по `запуск.bat`
- или в этой папке: `python aura_plm.py`

## Что умеет программа

- Дерево изделия слева (FeatureManager), свойства справа (PropertyManager)
- Карточки проекта, сборки и детали: имя, шифр/обозначение, тип, материал, количество, стоимость, работники
- Фото / GIF на карточке сборки и детали, просмотр 3D STEP и STL в окне AURA (вращение ЛКМ, масштаб колесом)
- Чек-листы оформления (ГОСТ/ISO) со статусами: не проверено / соответствует / замечание / не применимо. Можно убрать шаблон и вставить свой список
- Вкладка «Состав» — дети выбранного узла
- Библиотека материалов и типов изделий
- Новый / открыть / сохранить / сохранить как (`Ctrl+N`, `Ctrl+O`, `Ctrl+S`, `Ctrl+Shift+S`)
- Импорт JSON из HTML-менеджера проектов
- Связь с CAD и выгрузка состава в дерево
- Выгрузка состава из Siemens Teamcenter (PLMXML, briefcase, CSV BOM)
- Своё хранилище файлов (`Документы\AURA_Vault`): при импорте и создании детали/сборки файлы копируются в структуру проекта, CAD открывается из PLM
- Корзина покупнины: сборки «сборочная единица» разбираются на состав, остальное кладётся позицией. Экспорт в Excel (столбцы, ширины в мм, границы, фото) и иерархия проекта — как в менеджере проектов

## Файлы документа

Сохраняется JSON (например `aura-plm.json`). В нём проекты, библиотека, привязки CAD и чек-листы.

Открываются:

- полный документ AURA PLM
- экспорт HTML-менеджера: проект, сборка или деталь

## Связь с CAD

Группа **CAD** на панели команд или меню **CAD**.

| Кнопка | Действие |
|---|---|
| **Связь** | Окно обнаружения CAD, выгрузки и синхронизации |
| **Файл** | Выгрузить одну сборку или деталь |
| **Папка** | Выгрузить весь каталог проекта |
| **Тимц.** | Выгрузить состав из Teamcenter (PLMXML / CSV) |
| **Открыть** | Открыть выбранный узел в связанной CAD |

### Какие системы видит программа

При открытии **Связь** AURA смотрит реестр Windows, Program Files и список процессов. Для каждой системы показывается: установлена / не найдена, запущена / нет.

Поддерживаются: SolidWorks, КОМПАС-3D, Inventor, Solid Edge, Creo, Siemens NX, CATIA, T-FLEX, FreeCAD, AutoCAD, nanoCAD, **Siemens Teamcenter** и нейтральный STEP.

Кнопка **Обновить список** перечитывает статус.

### Как выгрузить проект сюда

**Файл сборки.** `CAD → Файл` или в окне связи «Выгрузить файл сборки…». Укажите `.sldasm`, `.a3d`, `.iam`, `.step` / `.stp`. Программа читает ссылки на компоненты и строит дерево. Детали ищутся в той же папке и во вложенных. Найденный файл привязывается к узлу. Если имя есть, а файла нет — создаётся заглушка «Файл не найден». Ссылки на Toolbox и внешние пути пропускаются.

**Папка проекта.** `CAD → Папка`. AURA обходит каталог, собирает сборки верхнего уровня и вложенность. Файлы, которые никуда не входят, попадают в сборку «Прочие детали».

**Запущенная CAD.** Откройте сборку в SolidWorks, КОМПАС-3D, Inventor, AutoCAD или NX и **сохраните** её на диск. В окне **Связь** выберите систему и нажмите «Забрать из запущенной CAD». Программа берёт путь активного документа (COM, заголовок окна NX, недавние файлы) и разбирает его как файл.

Если NX открыт **из Teamcenter**, локального `.prt` часто нет. Тогда AURA предложит выгрузить PLMXML из Teamcenter или указать файл вручную.

### Что появляется в дереве

Создаётся новый проект. Имя — имя файла или папки. У каждого узла блок **Файлы CAD**:

- SolidWorks (`.sldprt` / `.sldasm` / `.slddrw`)
- STEP (`.stp` / `.step`)
- нативный CAD (КОМПАС, Inventor и др.)
- PDF / чертёж

Можно привязать файл вручную (**…**), открыть в CAD (**Открыть**) или показать в проводнике (**Папка**).

### Синхронизация

Каждая выгрузка запоминается: система, путь, время. Список — внизу окна **Связь с CAD**.

**Синхронизировать состав** заново читает тот же путь и заменяет дерево сборок связанного проекта. Название, шифр и чек-лист проекта остаются.

Связи хранятся в JSON. Сохраните документ (`Ctrl+S`), чтобы не потерять выгрузку и привязки.

### Выгрузка из Teamcenter

Teamcenter не отдаёт дерево через обычный COM, как CAD. Нужен экспорт состава, который делает сам Teamcenter.

1. В Teamcenter откройте изделие в **Structure Manager** (или Active Workspace → структура).
2. Экспортируйте состав:
   - **PLMXML** (File → Export → PLMXML) — предпочтительно
   - **Briefcase** (`.bcz` / zip с XML)
   - **CSV / Excel-ведомость** с колонками уровня, обозначения, имени, количества
3. В AURA: **CAD → Тимц.** или **Связь → Teamcenter…**
4. Укажите выгруженный файл. Появится проект с тем же составом.

Обозначение (`item_id`) пишется в шифр/обозначение, ревизия — в поле ревизии, количество — в кол-во. Если рядом с PLMXML лежат JT/STEP/модели, они привязываются к узлам.

В окне **Связь** Teamcenter виден в списке систем (установлен / запущен). Синхронизация работает так же: повторно читается тот же PLMXML/CSV.

Типичные колонки CSV: `Level`, `Item ID`, `Revision`, `Name`, `Qty` (или русские: Уровень, Обозначение, Ревизия, Наименование, Количество).

### Хранилище файлов AURA

По умолчанию: `Документы\AURA_Vault`. Меняется в **Файл → Хранилище файлов…**.

Структура каждого проекта:

```
Projects/<имя>__<id>/
  00_Project/
  01_Assemblies/<сборка>__<id>/
    native/   step/   stl/   drawings/   photos/   docs/
  02_Parts/<деталь>__<id>/
    native/   step/   stl/   drawings/   photos/   docs/
  03_Imports/
```

- Импорт CAD / Teamcenter **копирует** модели в эти папки и переписывает пути в карточке.
- **Новый проект / сборка / деталь** сразу создаёт папки. Модель CAD сохраняйте в `native\`.
- На карточке сборки или детали: **Создать деталь в CAD…** — AURA показывает CAD, установленные на ПК (SolidWorks, NX, КОМПАС…), создаёт деталь в дереве и хранилище и открывает выбранную программу. Сохраните файл в `native\`.
- **В CAD** (или **CAD → Открыть в выбранной CAD…**) запускает SolidWorks, NX, КОМПАС и др. с файла из хранилища. Если файла ещё нет — открывает папку `native` и саму CAD.
- **Хран.** открывает папку текущего узла в проводнике.

### Открыть модель в CAD

Выберите сборку или деталь в дереве → **CAD → Открыть**. Файл открывается программой, назначенной в Windows для этого расширения.

### Типичный сценарий

1. Соберите изделие в SolidWorks и сохраните сборку.
2. В AURA: **CAD → Связь**.
3. Проверьте, что SolidWorks установлена (лучше ещё и запущена).
4. «Забрать из запущенной CAD» или укажите `.sldasm` / папку.
5. Проверьте дерево и пути в **Файлы CAD**.
6. Сохраните документ AURA.
7. После правок в CAD: **Связь → Синхронизировать состав**.

### Ограничения CAD-связи

- Документ в CAD должен быть сохранён на диск.
- Состав native-сборок читается по именам файлов внутри сборки, это не полный API BOM (конфигурации, подавления, Toolbox).
- Синхронизация обновляет состав целиком; правки внутри состава не сливаются построчно.
- «Открыть в CAD» использует файловую ассоциацию Windows.
